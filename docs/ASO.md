# ASO: discovery through search (hypothesis)

## Positioning

**Narrow query > broad casual game category.** Market keyword volume/difficulty has not been independently measured. Competitor downloads demonstrate only that related apps exist, not that keyword ranking is easy.

English working title: `Animal Shadow Match for Kids`

Japanese working title: `どうぶつのかげあわせ` (verify actual title length/metadata policy before store release)

English short description draft: `A gentle animal shadow matching game for ages 2–5. Tap, learn, and play offline.`

Japanese short description draft: `どうぶつと影をタップで合わせる、2〜5歳向けのやさしい知育ゲーム。オフライン対応。`

## Search themes to test

- `animal shadow match`, `shadow matching for kids`, `animal matching for toddlers`
- `toddler shadow puzzle`, `preschool shape matching`
- Japanese: `動物 影合わせ`, `幼児 シルエット クイズ`, `動物 形合わせ`

Do not stuff irrelevant keywords, other developers' trademarks, misleading claims, or age ratings into metadata. Check country-specific Google Play keyword and age disclosures before publish.

## Screenshot story (no misleading 3D claims)

1. Animal and **2** big silhouette options — simple tapping.
2. Animal and **3** silhouette options — variety.
3. Correct match with positive glow — positive feedback.
4. Several cute animals — breadth of reviewed illustrations.
5. Parent-facing truthful statement: offline and no ads (only if release build verifies both).

Store listing can be localized for parents while actual game remains text-free. Collect Play Console source/term-level data after publishing; choose future locales and keywords based on observed acquisition, not downloads of competing apps alone.
