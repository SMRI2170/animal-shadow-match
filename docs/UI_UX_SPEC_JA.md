## 0. 研究根拠と設計仮説

- Google Building for Kids: 一貫した簡潔なナビゲーション、控えめな効果、大きなタップ領域、複雑な複数指操作を避ける。 https://developers.google.com/building-for-kids/designing-engaging-apps
- NNG: 幼児を含む子どもの認知発達段階ごとにUIをテスト。対象を一括りにしない。 https://www.nngroup.com/reports/children-on-the-web/
- 幼児のタブレット研究: 2〜3歳児は複数指・手のひらの接触が起こりうるため、狭いボタンと精密なドラッグは初期操作に使わない。 https://pmc.ncbi.nlm.nih.gov/articles/PMC8200401/
- Google Play Families (現行公式ポリシーをリリース時再確認): 保護者用外部導線、データ安全、広告/SDKを別途審査。 https://support.google.com/googleplay/android-developer/answer/9893335

**注意:** 以下の寸法、ms、達成基準はチームの設計初期値/検証仮説であり、研究で確立した普遍的値ではない。対象ユーザーテストで調整すること。

## 1. 体験の原則（優先順位順）

1. **見れば分かる**: 一画面にカラー動物1匹+輪郭2〜4個。読ませない。
2. **一動作のみ**: 選択は大きなカードを1回タップ。ドラッグ・長押し・ピンチ・文字入力は必須にしない。
3. **最初の成功を最速で**: 起動後にタイトル/キャラ選択/チュートリアル説明画面を置かない。
4. **間違えても安心**: 誤答してもカード消去、減点、ライフ減少、ビープ音、振動を行わない。
5. **予測可能**: 不意の広告、モーダル、画面ジャンプ、位置の動き、長いアニメーションを避ける。
6. **騒がしくしない**: スパークルは控えめ、点滅なし、音を消しても明確。
7. **子どもの安全**: ストア/設定/外部リンク/課金をプレイUIから分離。
8. **動作の公平性**: 同じマスクから生成した影のみ、紛らわしい候補を使用しない。

## 2. 画面構成・情報設計

### S0: 起動/ロード (自動)
- 初回起動、再起動とも **直接S1へ**。独立したタイトル画面/名前入力/モード選択を追加しない。
- 目標: 手元端末で短時間ロード、画像はプレキャッシュ。読み込み中は**静止した動物の控えめな輪郭プレースホルダ**を示す。ロードが長い場合でも不必要なテキストや広告を表示しない。
- 画像読込失敗時: クラッシュや無限スピナーではなく、内蔵の正常画像へ安全にフォールバック。致命的エラー時のみ保護者向け導線を用意。

### S1: プレイ画面 (唯一の主画面)
```text
┌─────────────────────────────┐
│                      [⚙]    │ ← 隅の保護者用入口（低視覚優先度）
│                             │
│           [ 動物 ]          │ ← カラー動物、全身、画面中央、切れなし
│                             │
│            ↓                │ ← 初回だけ手のガイド(操作ではない)
│     ┌────────┐ ┌────────┐ │
│     │   影A  │ │   影B  │ │ ← 2択。カード間に十分な隙間
│     └────────┘ └────────┘ │
│                             │
└─────────────────────────────┘
```
- 上: カラーのターゲット1匹。背景に複雑な物体/文字/擬似ボタンを描かない。
- 下: 2択→3択（上2+下1センター）→4択（2×2）。**必ず全候補をスクロール無しで表示**。難易度移行後もカードの外観/動作は同じ。
- 上の動物は**触っても誤答にならない**。手のひら/余白タップを無視。候補以外に正解/不正解判定なし。
- 5つの星・スコア・タイマー・ライフをプレイ画面から削除。収集要素を初期版に入れない。
- ⚙は可能ならホーム画面内に置かず、目立たない保護者用入口として配置。外部リンクや購入画面は検証済みの年齢相応の保護者ゲートの後ろに置く（単なる長押しのみをゲートと見なさない）。
- OS戻る操作を不必要に奪わない。確認ダイアログで子どもに読字を強制しない。保護者設定側のみ必要な文章UIを許可。

### S2: 正解のフィードバック
- 入力直後（目標100ms以内に視覚反応開始）に**選ばれた影を同位置でカラー動物へ200〜350msでクロスフェード**。元の大きさから極端に拡大させない。
- 動物を少しバウンス（scale 1→1.06→1、合計300〜450ms）。控えめなキラキラ最大3個。点滅・紙吹雪の連射禁止。
- 目安として**全体1.1〜1.5秒**で次の問題へ。出題まで入力ロック。アニメーションを減らすOS設定/無音でも正解の区別が付く。
- 選んだカード以外を移動させず、出題の切替は一括で行う。前の影を連打して次の問題に誤答しない（遷移前ロック+遷移直後150msガード）。

### S3: 誤答のフィードバック
- タップ直後、選択カードを100〜160msだけ軽く押し込む/元に戻す。必要なら薄いニュートラル色の縁取り。**赤×、悲しい顔、爆音、画面揺れ、減点なし**。
- 誤答直後も同じ選択肢・動物・並びを保持。誤答候補の位置を動かさない。
- 連続2回以上迷っている場合のみ、正解カードに**淡い輪郭パルスを1回**（課題放棄を誘う強い強調は避ける）。誤答をカウントして幼児を責めない。
- 故意の連打で音や演出が重ならないようデバウンスを実装。

### S4: 保護者専用エリア (MVPでは最小)
- ゲーム本体から独立。文字UIあり。将来導入するなら静かな音ON/OFF、難易度「やさしい/自動」、プライバシーポリシー、クレジット等。
- 画面から外部サイトへ遷移するときは適切な保護者ゲートを使用する。未設置なら外部リンク自体を出さない。
- **MVPでは設定画面も音機能も未実装可**。その場合は遊び画面に無意味な⚙ボタンを表示しない。UIにあるボタンは必ず動くこと。
- 課金・広告・ログイン・SNSシェア・PushをMVPに追加しない。

## 3. レイアウト/デザイントークン

| 変数 | 初期値 | ねらい |
|---|---|---|
| 背景 | `#FFF9F0` | 明るいクリーム。白カードとの段差で強弱をつける |
| 影 | `#253134` | 暗い青みグレー、輪郭を鮮明にする |
| カード | `#FFFFFF`、角丸24〜28dp、控えめな影 | 押せる物と分かる |
| 情報量 | 動物1匹、選択肢2〜4個、任意の保護者入口1個 | 同時注意を抑える |
| カード最小タップ領域 | **96×96dp目安、可能なら120〜152dp** | 子どもの指でも押しやすくする |
| カード間隔 | 12〜16dp目安 | 誤タップ防止 |
| 周囲の余白 | 左右16dp以上 + SafeArea | 手のひらを置く領域 |
| 上の動物 | 長辺が画面幅の55〜75%程度・contain | 全身と特徴を見やすく |
| 文字 | 子ども画面: 0 / Semantics: 必須 | 言語独立 + 補助機能 |
| モーション | 150〜450msの部分反応/約1.1〜1.5sの正解遷移 | 分かりやすく穏やかに |
| 方向 | Androidスマホ縦向きMVP。タブレットは拡大せず中央寄せ | どの端末でも比較的同じ操作 |

- **360×640dp、393×851dp、800×1280dp**でSafeArea込みの画像検証。Androidの表示倍率/文字倍率も確認。
- 小さい端末で4択が高さに収まらなければ、画像表示の大きさ/余白を縮小する。**選択肢をスクロールさせない/タッチターゲットを96dp未満に縮めない**。解消不能なら自動的に選択肢数を減らす。
- 正誤判定を色だけに依存させない。
- `AnimatedScale`などを使うときはタップ領域・描画順・HitTestが変わらないようにする。

## 4. 初回ガイド (説明を読む必要なし)

- 初回: 2択。初期画面が表示され約2〜3秒間、ユーザー操作がなければ淡い手のポインタが対象動物→正解の影の順に1度だけ移動し、影の輪郭が短く光る。
- 手/ヒントは**子どもが触れた瞬間に消える**。手の動作はゲーム内のタップ判定に介入しない。初回から説明文・読み上げ・強制操作を出さない。
- 8〜10秒無操作なら同じガイドを1度、以後は一定の無操作時間を経過したら穏やかに再表示。連続で動き続けない。
- Playtestingで「手が正解を教えすぎて遊びにならない」場合は、**正解カードではなく候補全体を軽く強調**する方式を比較する（A/Bは保護者同意のローカル観察のみ）。

## 5. 難易度とコンテンツ

- 2択を最初の5成功は維持。3択はその後、15成功後に4択という現行ロジックを初期値として維持する。
- UI上に「レベル1/2/3」と表示しない。動物と影の大きさ・強さで難易度を変える。
- 年齢でなく**実際の理解度**で難易度を変える。目安: 直近5問中4問以上を迷わず解けるなら次段階、同じ難度で3問連続して誤答が多い場合は1段階下げる。プレイ記録では「正解までに何回タップしたか」を個人識別なくローカルで集計する。
- 昇降格を頻繁に繰り返さない（ヒステリシス/最低5ラウンド維持）。4択の候補が曖昧なら影の近似度より**目視QAのNGペアリスト**を優先。
- 子どもの「クリア」を強制しない。いつでもアプリを閉じて再開できる。
- 次問で答えの場所と動物の順番をランダム化。ただし選択肢が毎フレーム動くことは禁止。

## 6. 音・アニメーション・視覚表現

- MiniMaxは**1枚に動物1匹、全身、単色背景、輪郭がはっきりしたソフト3D/絵本風**を独立生成。影は同じalpha maskから生成。実装画像を別途生成して輪郭合わせを試みない。
- 動物はできるだけ同じ視線方向/縮尺/余白で統一する。耳、しっぽ、脚の輪郭が隠れた画像を採用しない。生成画像が派手でもUIの背景は静かに保つ。
- 音は後から任意追加。タップ/成功音は短いものにし、音が出なくても色以外の視覚変化で正誤を認識できるようにする。端末のアクセシビリティ設定 `disableAnimations` や reduce-motion 相当を尊重。
- 発光の連続点滅、強い振動、勝ち負けを煽る演出、無限に連続する背景動作は禁止。

## 7. UI状態機械・Flutter設計

```text
loading --success--> ready --tap wrong--> subtleFeedback --> ready
   |                     |
   +--error--> fallback  +--tap correct--> celebrating --> transitioning --> ready(next)
                         |
                         +--open parent--> parentArea --> ready
app background: pause timers/animation; app resume: same round, no accidental auto-advance
```

- `lib/ui/game_page.dart` は表示に責務を限定。 `RoundController`（追加）で状態`loading/ready/wrongFeedback/celebrating/transitioning`を管理し、正解後に再タップしないよう保証。
- タイマーは画面dispose/アプリ背景化時にキャンセルまたは停止。復帰時は**同じ問題をreadyで再表示**（回答済みなら遷移仕様を明示）。
- カードは `Semantics(button:true, label: localized animal silhouette, enabled: ...)` とし、スクリーンリーダー時に選択内容が読み取れる。画像には読みやすいラベルを設定し、補助機能向けテキストはローカライズ可能にする。
- 初回案内/正誤音/成功演出はそれぞれ無効化可能なモジュールとする。外部パッケージを安易に増やさない。

## 8. 子どもを対象にした使いやすさ試験

**保護者の同意**を得た2〜3歳、4〜5歳のそれぞれ3名以上（できれば合計10名以上）。数値はMVPの探索的合格基準であって統計的有意性を意味しない。氏名、顔動画などの個人情報を収集しない。観察時は保護者同席。

観察手順:
1. アプリを起動した状態で子どもに渡し、大人はやり方を説明しない（安全の補助のみ）。
2. 最初の3問で「タップする場所」「最初の正解までの時間」「誤タップ」「必要な助け」を記録。
3. 5問程度を続けてもらい、正答後の反応が伝わるか、途中で手が止まるか観察。
4. オフライン/ミュート/短いアプリ中断を再現し、復帰できるか確認。

初期の暫定ゲート:
- 初めの3問以内に、観察対象の80%以上が大人の操作補助なしで最低1回正答。
- 最初の正答まで中央値15秒以内（第一問の画像表示後、開始秒を統一）。
- 誤タップや多指接触が起きてもクラッシュ・画面逸脱・誤遷移0。
- 3問以上プレイした子のうち80%以上が次問も操作できる。
- 数値達成だけで満足せず、失敗の行動パターンを設計修正する。年齢・運動発達差が大きい場合はセグメント別に報告する。

## 9. テスト受入条件 (Definition of Done)

- [ ] 起動から追加のスタートタップ無しで2択が表示される。
- [ ] 初見の子どもに**読むべき文字が0**。設定等はプレイ画面外。
- [ ] 2/3/4択で全カードがスクロール無し表示、カード96dp以上。360×640, 393×851, 800×1280で確認。
- [ ] 誤答で候補順が変わらず、責める演出・減点・バイブ無し。
- [ ] 正解後の連打でも遷移は一度だけ、新問題に誤タップを持ち越さない。
- [ ] 起動後2〜3s、無入力8〜10sのガイド挙動とタッチでの中断を確認。
- [ ] 視覚変化だけで正誤を判断でき、ミュートでも同じ問題解決ができる。
- [ ] 無音設定、reduce-motion、ScreenReader、OSバック/復帰、画像ロード失敗を確認。
- [ ] 類似影の組み合わせを除外し、最終素材のみ使用。
- [ ] 保護者の同意を得た試遊結果から、改善決定を記録。
- [ ] UIで表示する操作可能なコントロールは実際に機能する。
