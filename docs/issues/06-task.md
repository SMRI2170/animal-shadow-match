# [P0][Pipeline] 背景除去と影生成の自動処理

## 目的
背景除去済みのカラー動物画像1枚から、同じ輪郭の影を自動生成する。

## 実装
- MiniMaxの生成画像を外部またはオフライン処理で背景除去し、RGBA PNGで保存。
- `scripts/prepare_assets.py` でトリム、512px正規化、WebP最適化、アルファマスクから影生成。
- 全面不透明画像を明示的に拒否する。
- 細い耳・ひげ・アンテナ・尾が消失していないかQAで確認する。
- 100枚一括処理で再実行可能にする。

## 受入基準
- [ ] 1ファイル入力からカラーと影の2ファイル出力。
- [ ] 影とカラーのマスク形状が完全一致。
- [ ] 不透明背景でパイプラインがエラーを出す。
- [ ] 再実行で同名の意図しない重複ファイルが増えない。
