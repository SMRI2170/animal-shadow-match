# [P1][Release] Android内部テスト公開と最終ゲート

## 目的
開発用画像を本番用画像に全置換し、安全にGoogle Playの内部テストへ公開する。

## 実装
- 100枚を目標に本番MiniMax画像を審査し、デモ画像を残さない。
- アプリID、アイコン、署名、AAB、target SDKなどその時点の公式要件に適合。
- Android実機でネットワークOFFの起動・繰り返しテストを行う。
- Play Consoleの審査情報、プライバシーポリシー、コンテンツレーティングを整える。
- まず内部テストへ配布し、不具合を修正。

## 受入基準
- [ ] 100%本番許諾済みアセット。
- [ ] 全GitHub Actionsのチェックが通る。
- [ ] 内部テスト版AABがアップロードできる。
- [ ] 意図しないSDK/権限・鍵の漏洩がない。
- [ ] ストアの対象年齢と宣言が一致する。
