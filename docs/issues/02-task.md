# [P0][Gameplay] 文字なし1画面ゲームUIの完成

## 目的
文字を読めない2〜5歳児が1画面で「動物を見る→影をタップ」を理解できる体験を作る。

## 実装
- 画面上部にカラー動物、下部に候補シルエット2〜4枚。
- ボタンは最低96dp程度を目安とし、360dp幅でも欠けない可変レイアウト。
- 問題画面に説明文、文字ボタン、スコア、制限時間、課金導線を出さない。
- `Semantics` には動物名・ボタン種別を提供し、子ども向け画面の文字ゼロと両立。
- タップ連打・戻る・アプリ復帰時の安全性を確認。

## 受入基準
- [ ] 360dp幅の縦画面で2/3/4択が視認できる。
- [ ] 候補は押せる領域が十分に広い。
- [ ] UI上の文字がなくても初回プレイ可能。
- [ ] 正誤判定が表示フレームと同期しており、別問題への誤タップが発生しない。
