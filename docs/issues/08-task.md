# [P1][UX] 反応・効果音・ミュートの追加

## 目的
正答時に心地よい反応を返す一方、刺激過多や親の困りごとを避ける。

## 実装
- 正解時に短いポップ/バウンス効果と柔らかい確認音。
- 不正解時は軽い色変化のみ（大きな警告音・震えは禁止）。
- 保護者向けミュート設定を追加し、初期音量は控えめ。
- サウンド素材は権利確認できるもののみ同梱する。

## 受入基準
- [ ] 効果は正解タップから即時に始まる。
- [ ] ミュート中は無音。
- [ ] 連打で複数音が重ならない。
- [ ] 子ども向けに不快な大音量を出さない。
