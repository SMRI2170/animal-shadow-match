# [P0][MiniMax] ソフト3D動物画像20種を生成して選定

## 目的
MiniMaxで1枚ずつ完成した動物を出力し、影合わせゲームとして成立する最初の20種類を確保する。

## 実装
- `docs/ASSET_PIPELINE.md` にあるスタイル固定プロンプトを基準にする。
- 画像は1匹、全身、輪郭が明瞭、背景分離しやすい構図で生成。
- 不自然な肢体、切断、怖い印象、ロゴ/文字入り、影が複雑な画像は除外。
- 成果物の生成モデル、日時、プロンプト版、レビュー担当を記録。
- Image-01の商用利用条件と素材利用権を公開前に確認。

## 受入基準
- [ ] 20匹以上の異なる動物の採用画像。
- [ ] 小さい表示でも動物が識別できる。
- [ ] カラーと黒い影を並べた目視QA完了。
- [ ] 全採用画像の利用権・安全性を記録。
