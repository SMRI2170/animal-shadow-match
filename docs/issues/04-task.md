# [P0][Assets] 画像・影・メタデータのスキーマ固定

## 目的
画像を100枚以上に増やしても、個別コード修正なしで動作するデータ構造を固定する。

## 実装
- `assets/catalog/animals.json` のID、画像パス、影パス、カテゴリ、distractorsを定義。
- 画像名は英小文字・数字・アンダースコアに統一。
- `scripts/validate_catalog.py` で存在、重複、参照、アルファ一致をチェック。
- 不正データはCIで失敗させる。
- 必要ならJSON schemaファイルを用意する。

## 受入基準
- [ ] ファイル欠落、重複ID、存在しないdistractorをそれぞれ検出。
- [ ] カラーと影のアルファが一致。
- [ ] 新画像を追加してもDartコードの変更不要。
- [ ] 8枚の開発用画像は本番公開前に置換される。
