# [P0][Logic] 問題生成ロジックのテストと難易度調整

## 目的
正答が1つだけ存在する問題をオフラインで安定生成し、児童が難しすぎる問題に遭遇しないようにする。

## 実装
- `RoundFactory` を唯一の問題生成処理とし、乱数を注入可能に保つ。
- 0〜4回正答:2択、5〜14回:3択、15回以降:4択。
- 直前の正答動物の連続提示を防止。
- `distractors` に登録した候補を優先し、未登録IDは検証で落とす。
- 同一シルエットに見える組み合わせをQAシートで排除。

## 受入基準
- [ ] 1000ラウンドの自動試験で選択肢重複ゼロ。
- [ ] 常に1つだけ正解がある。
- [ ] 5回/15回の切替テストあり。
- [ ] 間違いを何回押しても正解回数は増えない。
