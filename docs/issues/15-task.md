# [P2][Growth] 検索流入30〜60日検証

## 目的
「影合わせ」というニッチで検索のみから継続的にユーザーを獲得できるか検証する。

## 実装
- Google Play Consoleで検索経由の獲得、訪問数、インストール数、検索語句の可視範囲を記録する。
- ストアのアイコンや主画像の改善を小さく試す。
- トラッキングSDKや保護者の許可のない個人データ収集は行わない。
- 需要が少なければ一般的なジグソーへ転換せず、類似ニッチキーワードを比較する。

## 受入基準
- [ ] 30日と60日時点の成果指標が整理される。
- [ ] 検索流入仮説がデータに基づき支持/棄却される。
- [ ] 次の画像追加またはASO改善が優先順位付けされる。
