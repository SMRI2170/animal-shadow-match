# [P1][Responsive] 小画面・タブレット・アクセシビリティ

## 目的
世界中の一般的なAndroid端末で見切れず操作できることを確認する。

## 実装
- 360x640dp、393x851dp、タブレット縦長でスクリーンショットテスト。
- 横画面は初期MVPで非推奨または専用レイアウト設計（無理に縦UIを伸ばさない）。
- SafeArea、文字倍率、スクリーンリーダーラベル、フォーカスを確認。
- 色だけで正誤を判別させない。

## 受入基準
- [ ] 最小サポート画面ですべての選択肢に触れられる。
- [ ] 影の上下左右が切れない。
- [ ] Semanticsラベルが意図通り。
- [ ] 音がなくても問題が成立する。
