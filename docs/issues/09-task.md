# [P1][Progress] ローカル保存と適応難易度

## 目的
アプリ再起動後に進行状況を保持し、学習進度に適した問題数を提示する。

## 実装
- オンデバイスにプレイ進行状況のみ保存。識別子や個人情報は保存しない。
- 初回は必ず2択で開始、5/15問で自然に増加。
- 容易に2択に戻れる保護者導線を検討する。
- 保存データ破損時は安全に初期値へ復帰する。

## 受入基準
- [ ] アプリ再起動後に難易度が意図通り維持される。
- [ ] オンラインアカウントは不要。
- [ ] 子ども側に複雑な設定画面を出さない。
- [ ] 保存データ破損でクラッシュしない。
