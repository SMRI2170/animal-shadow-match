# [P0][Safety] 子ども向けポリシーとプライバシー

## 目的
Google PlayのFamiliesポリシーとデータ安全要件に対応した、安全なMVPを公開する。

## 実装
- 対象年齢を5歳以下のアプリとして適切に申告（公式要件で最終確認）。
- 広告SDK・トラッキングSDK・アカウント機能・ランタイムAI APIを導入しない。
- プライバシーポリシーを実態に合わせて公開し、Play Console申告を照合する。
- 外部リンクや保護者設定があれば適切な保護者向け導線を設計する。
- 画像・効果音・アイコン素材の著作権や商用利用条件を確認する。

## 受入基準
- [ ] Familiesポリシーのレビュー記録あり。
- [ ] Data Safetyの申告が実装に一致。
- [ ] プライバシーポリシーURLがあり、実態に一致。
- [ ] 広告・解析・不要な権限なし。
- [ ] 法的・知財上の未解決事項がない。
