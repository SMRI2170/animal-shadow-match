# [P1][ASO] 英語・日本語ストア掲載素材

## 目的
検索意図が明確な保護者に対して、広告なしでアプリ価値を正しく伝える。

## 実装
- 英語タイトル `Animal Shadow Match for Kids`、日本語タイトル `どうぶつのかげあわせ` を作業仮案として見直す。
- 正確なゲーム画面を使った5枚のストアスクリーンショットと高解像度アイコン制作。
- `animal shadow matching`, `toddler shadow puzzle`, `幼児 シルエット` などの関連語をASO仮説として検証。
- Playストア規約に違反する誇大広告・未取得のバッジを使用しない。

## 受入基準
- [ ] 英語・日本語のタイトル/短い説明/本文が用意される。
- [ ] ストア画像が実際の機能を正確に示す。
- [ ] タイトル文字数・画像仕様を公開直前に確認。
- [ ] ユーザーが一目で影合わせだと理解できる。
