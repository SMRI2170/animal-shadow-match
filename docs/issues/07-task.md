# [P0][Content] 影の紛らわしさをレビューする仕組み

## 目的
イラストが良くても「正解が複数に見える」問題を作らない。

## 実装
- 各採用動物の影だけを一覧表示するQAギャラリー（HTMLまたはローカル画像）を作る。
- 同一サイズの影に正規化し、近い輪郭候補をレビュー対象として記録。
- 各問題で選んではいけない候補（見分けづらい組合せ）を除外できるデータ設計にする。
- 2〜5歳児と保護者の試験で「誤答しやすい問題」を取り除く。

## 受入基準
- [ ] 影だけを一覧で見られる。
- [ ] QA済みの候補セットのみが公開ビルドで使われる。
- [ ] 少なくとも20問の試遊記録がある。
- [ ] 不明瞭な問題があれば除外できる。
