## リリース前の初期仮説ゲート（統計的保証ではない）
- 80%以上が最初の3問以内に保護者操作の補助なく1回正答
- 最初の正答までの中央値15秒以内（画面表示開始から測定）
- 誤タップ、多指接触、端末復帰によるクラッシュ・意図しない画面遷移0
- 年齢ごとの違いが大きい場合は表示/難易度設定を見直す

基準を満たさなくても子どもを失敗扱いしない。**UI・素材・出題の方を改善**する。公式[UI/UX仕様](UI_UX_SPEC_JA.md)と[GitHub Issue #19](https://github.com/SMRI2170/animal-shadow-match/issues/19)を参照。
