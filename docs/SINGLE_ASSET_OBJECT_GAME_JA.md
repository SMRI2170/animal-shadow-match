# 画像1枚で遊ぶ「ぷにぷにふしぎなモノ」 — ゲーム設計 v6

> 2026-10-14。**今回の採用方針**：動物・架空キャラの量産を前提とせず、顔や手足のない「触感が想像できる不思議な物体」を主題にする。実装とMiniMax本番画像は未完了。リポジトリ名は変えない。
> 優先順: **v6は素材ジャンル・画像加工・リアクション設計についてv5（ふしぎなキャラ検討）/v4（動物別アニメ）を上書き**。v3の5問一区切り・続行/休憩・広告なし、v2のタップ中心・文字なし・大きな押下領域は維持。

## 1. 製品仮説と差別化

- 子どもは「影と同じ形を見つける」ことに加え、「触るとぷにっと膨らむ、震える、弾む、くるっと回る」といった**因果のある反応**を楽しめる。
- **骨格、ボーン、モーション素材、連続ポーズ、キャラの一貫性を全く要求しない**。1枚の透過オブジェクト画像から影（アルファマスク）を自動作成し、ゲーム中の動きは原則コードによる画像全体の2D変換で表現する。
- 一枚目は未完成のカプセルやステージ絵ではなく、**それ自体が完成した単独の物体**を生成する。別画像と一致させる「開ける前/開けた後」のペアは作らない。
- 「Pop It」「Surprise Eggs」にはGoogle Playで1千万DL級の競合作品がある。**物体を押せば即ブルーオーシャンとは言わない**。「影当て + 個性的な単体アセットの触り心地 + 自由遊び」を組み合わせたUXとして検証する。
- 初回はタップのみ、子ども画面は文字・ライフ・スコア・課金・広告なし。保護者と子どもが中断しやすい区切りを維持。

## 2. 素材テイスト — 非キャラクター・単体オブジェクト

**第一候補は「ぷにぷにふしぎなモノ」**。色は柔らかいパステル、素材感はマットなゼリー・柔らかい粘土・スポンジ・ゴム・半透明樹脂。顔・動物の目・手足・洋服・人間的な骨格を付けない。

形の例：
- ゼリーのような星、雲、しずく、ぷっくりしたハート
- 真珠っぽいリング、ふわふわした角丸の結晶、謎のクッション
- ねじれたグミ、凹凸のあるゼリーキューブ、波形の円盤
- へんな形の宝石、柔らかい惑星のような球、丸い突起を持つ不思議なオブジェ

**避けるもの**：既存有名キャラ、商標やブランドロゴ、顔・四肢で動くことが期待される生き物、輪郭がほぼ同じ単なる色違い、細くて切れやすい突起、単体に見えない集合画像、実在の商品と見間違う危険な物。

画像のプロンプトは **共通の画風指定 + 個別の形状1〜2条件** だけ。構図統一は厳密な再現より、中央1個・全身/全体が収まる・単色背景・3D soft toy style を守る。候補ごとに独立生成してよい。

### 生成〜アプリ導入
`MiniMax (1物体1画像)` → 人手選定 → 透明化(人手目視) → アルファ輪郭から影を生成 → 同一源泉の画像/影WebPを出力 → JSONへのID・形・反応プリセット付与 → QA

厳密にはアプリ内に「色つき画像と影の2ファイル」を配置しても、**絵として生成・制作する元画像は1枚**。影は機械生成で、新しいイラスト素材ではない。

## 3. ワンアセットFXの実装難易度

| FX | 利用操作 | Flutter実装の目安 | 一枚でできることと限界 | MVP |
|---|---|---|---|---|
| SQUISH ぷにっ | タップ | scaleX 1→1.12→1、scaleY 1→0.88→1 / easeOutBack | ラスター画像全体を楕円変形。局所変形まではしない | **必須** |
| WOBBLE ぷるぷる | タップ | 角度 ±4〜7° を減衰振動、わずかなscale | 質感は動かないが柔らかさを感じられる | **必須** |
| BOUNCE ぽよん | タップ | translateY 0→-12dp→0、着地squash | ボーン不要、接地点からアニメさせる | **必須** |
| INFLATE ぷくー | タップ（短い） | scale 1→1.2→1、幅方向優先も可 | 奥行きの真の体積変化や光源変更はしない | **必須** |
| SPIN くるっ | タップ | rotate 0→±12°→0 / 1回転は平面に見えるため基本禁止 | 2D板状の回転。3D自転は再現できない | **任意** |
| POP 消える | タップ | scale + opacity で消えて再出現、コード粒子3〜6個 | 実際の破裂断面は描けない。復元は同じ画像 | **任意** |
| SPLIT ぱかっ | 任意 / 実験 | 同一画像をClipRect2枚またはCustomClipperで分け左右にtranslate | 画像断面は無い。紙が切れたように離れるのみ。真の中身・厚みは別素材が必要 | **P1実験** |

Flutter reference: https://api.flutter.dev/flutter/widgets/Transform-class.html , https://api.flutter.dev/flutter/widgets/AnimatedScale-class.html , https://api.flutter.dev/flutter/widgets/ClipRect-class.html

**重要**: 大幅な3D回転、目の瞬き、脚の歩行、口の開閉、しわや局所メッシュの自然な変形、物体を半分に割って現実的な断面を見せる表現は、一枚のラスター画像から**無理に実現しない**。上記はあくまで平面画像の変形や描画効果である。

## 4. 具体的なゲーム体験

### 1問
1. 画面上に完成したカラーの物体が1つ、下に同じ影を含む大きな2択（後で3/4択）。
2. 影をタップすると選んだ影がカラー物体にクロスフェード。選択と同時に小さな押下反応。
3. 正解時、その物体に設定されたFXを**1回**再生し、1.1〜1.5秒程度（仮）で次の問題。FXの種類を事前に教えず、動きが変わること自体を小さな発見にする。
4. 誤答は軽い押下だけ。罰・カウント減・効果音依存・広告なし。

### 5問終了
- 直近の5個の物体を展示した**ぷにぷにプレイエリア**を開く。正解したオブジェクト画像の再利用だけで成立。
- 子どもが好きな物体をタップすると、その物体だけが設定済みFXを再生。**自分で起こす現象を繰り返し楽しむ**ことを価値にする。時間制限・ポイント・抽選なし。
- 続ける（次の5問）/休憩はこれまで通り大きな絵ボタン。画面が小さいときは展示をページ切り替えし、96dp未満の細かい当たり判定にしない。

### プレイ中の初回説明
- 何もしなくても画面は静か。2〜3秒無操作時に指が「下のカードを1回触れる動作」を示す（正解位置を即ネタバレしない）。8〜10秒以上の無入力で助けを検討。誤答しても同じ問題。

## 5. データモデル — 動物に依存しない名前にする

アプリ内クラス`Animal`,`RoundFactory`等の責務は段階移行で**ShadowItem** / `ShadowRound` / `AssetCatalog`へ整理する。命名変更時は既存の8種デモ素材/Unitテスト/CIが動く状態を保ち、移行PRで一度に全部消さない。

```json
{
  "id": "toy_001",
  "image": "assets/items/toy_001.webp",
  "shadow": "assets/items/toy_001_shadow.webp",
  "category": "squishy_object",
  "silhouetteFeatures": ["star_outline", "rounded_tips"],
  "effectPreset": "squish",
  "effectIntensity": "gentle",
  "distractors": ["toy_007", "toy_009"]
}
```

- JSON IDは英小文字/数字/アンダースコア。effectPreset未記載時はsquishをdefault。
- `effectPreset`: squish / wobble / bounce / inflate / spin / pop / split（splitはMVPでは非有効）。
- `effectIntensity`はgentleのみを初期採用。光点滅/激しい揺れ/バイブなし。
- JSONを解釈するのはDomain層、動かすのは`SingleAssetEffectWidget`。各エフェクトをif文で巨大UIに直書きしない。
- 画像は中央寄せ+透明余白が統一された元画像。影のマスクの一致をvalidate_catalog.pyで確認。最終的な画像と影はランタイムでネット生成しない。
- FXのhitTestは元カード枠に固定。変形により隣のカードへのタップが誤選択されない。
- 描画性能: 60fpsを目標として実機測定。端末を過剰に振動させず、reduce motion時は静的な色変化のみ。

## 6. 題材選定・試作の最短経路

v5の「オリジナルキャラ20枚+魔法の道具12枚」の試作は**置き換え**る。まず下記の3グループで合計30枚のみ生成し、動かしてから本番100〜200枚に増やす。

| グループ | 枚数 | 内容 |
|---|---:|---|
| A ゼリー/グミ/クッション | 12 | ぷにぷに感が伝わる。星、雲、しずく、ゆがんだ輪、立体キューブなど |
| B ふしぎなおもちゃ | 10 | 柔らかなリング、くるくる円盤、ぽこぽこボール、ねじれ形 |
| C 不思議な自然/宇宙オブジェクト | 8 | 柔らかい石、雲、惑星、結晶、しずくなど（実在物の再現にはこだわらない） |

**採用ゲート**:
- [ ] 少なくとも20/30枚が「完成した単体物体」「背景除去可能」「96dpの影で見分けやすい」「怖くない」を満たす。
- [ ] 5種の主要FXが画像1枚で違和感なく見えるか確認。合わないオブジェクトへのエフェクトは割り当てを変える。
- [ ] 影が色違いで同形に見える候補を組み合わせない。色の違いではなくシルエットで識別できるかを確認。
- [ ] 動物との比較が必要なら旧8種をベースラインにするが、**大量にキャラ生成する試作はしない**。
- [ ] 2〜3歳、4〜5歳に保護者の同意を得た小規模試遊。「何をタップしたか」「自分で再タップしたか」「5個を自由に試したか」「割れて見える演出が怖くないか」を匿名観察。
- [ ] 100枚量産の判断はこの試作のQA後。商標/既存キャラ/アセット商用利用条件を再確認。
